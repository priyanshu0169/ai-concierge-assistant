Host page

This page stands in for a storefront. It contains no assistant code of its own — only the script tag below, which is the entire integration. 

<script src="/shopsage.js"
        data-backend-url="http://127.0.0.1:4100"
        data-token-url="http://127.0.0.1:8700/assistant/session"
        defer></script>

Everything the panel shows about the store — its name, greeting, colours, suggested questions and message ceiling — arrives from GET /v1/config at run time. The same bundle serves any store, and any future platform: nothing in it mentions Magento, and data-token-url is simply wherever this host mints a session token.

What to check by hand

  • Tab to the launcher and press Enter — focus should land in the input.
  • Press Escape — the panel closes and focus returns to the launcher, not to the page top.
  • Ask something answerable and watch the answer arrive token by token.
  • Ask a follow-up; refresh the page and ask another — the conversation should continue.
  • Narrow the window below 480px — the panel should go full screen.
  • Turn on a screen reader: the answer is announced politely, without interrupting.
